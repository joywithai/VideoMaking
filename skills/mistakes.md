# mistakes.md — যেসব ভুল হয়েছে, যেগুলো দ্বিতীয়বার কোনোদিন হবে না

> **সেলফ-লার্নিং নিয়ম (বাধ্যতামূলক):** প্রতিটা build-এ যখনই কোনো ভুল ধরা পড়ে —
> ইউজার ধরালে, validation ধরলে, বা নিজে ধরলে — **সাথে সাথে** নিচের format-এ
> এই ফাইলে entry যোগ করো, তারপরেই কাজ চালিয়ে যাও। পুরনো entry কখনো মুছবে না।
>
> **Entry format:**
> ```
> ## M{N}. {সংক্ষিপ্ত শিরোনাম} [topic/তারিখ]
> - **লক্ষণ:** কী দেখা গেল/ইউজার কী বলল
> - **কারণ:** root cause
> - **সমাধান:** কী করে ঠিক করা হলো
> - **নিয়ম:** পরে যা করবে/করবে না (এক লাইনে, পরীক্ষাযোগ্য)
> ```
> নতুন entry নম্বর = শেষ নম্বর + 1। প্রতিটা skill file-এর নিয়মগুলোও এখান থেকেই তৈরি —
> তাই নতুন ভুল এলে সংশ্লিষ্ট skill file-ও হালনাগাদ করবে।

## M1. Transform নিজের input-এর উপর লিখে ফেলেছিল (SRT ধ্বংস) [JWT/2026-10]
- **লক্ষণ:** SRT align script চালানোর পর মূল SRT-এর সব time নষ্ট — পুনরুদ্ধার করতে হয়েছে।
- **কারণ:** script-এ SRT_IN == SRT_OUT পাথ ছিল; প্রথম run-ই ইনপুট ফাইলটাই ওভাররাইট করে দেয়।
- **সমাধান:** আলাদা আউটপুট পাথ; নতুন ফাইল যাচাইয়ের পর replace।
- **নিয়ম:** কোনো transform কখনো নিজের input file-এ লিখবে না; সবসময় temp → validate → replace।

## M2. Anchor ছাড়া (unanchored) অ্যালাইনমেন্ট = systematic drift [JWT/2026-10]
- **লক্ষণ:** DP-based word align সব cue ~1.5s দেরিতে সরিয়ে দিয়েছিল।
- **কারণ:** শুধু duration fit করে ভুল island-এ শব্দ বসানো; কোনো anchor ছিল না।
- **সমাধান:** cue time কখনো নড়াবে না (TTS chunk = exact); শুধু word গুলো cue-এর ভেতরে VAD island-এ বসানো।
- **নিয়ম:** অ্যালাইনমেন্টে সবসময় chunk/cue time authoritative; কখনো নতুন cue time বানাবে না।

## M3. হারানো data মেমোরি থেকে পুনর্গঠন (fabricated recovery) [JWT/2026-10]
- **লক্ষণ:** SRT-এর cue time/text পুনরুদ্ধার করতে গিয়ে আসল টাইমিং ও লেখা উভয়ই ভিন্ন হয়ে গিয়েছিল — ভিডিওতে ~3% জায়গায় ভিজ্যুয়াল দেরিতে আসা, কিছু লেখা প্যারাফ্রেজড।
- **কারণ:** স্যান্ডবক্স রিসেটের পর টুল আউটপুট থেকে "মনে করে" টাইম/লেখা টাইপ করা — যা ছিল না।
- **সমাধান:** git history থেকে আসল ফাইল ফিরে এসেছে (TTS chunk time = সত্য)।
- **নিয়ম:** data কখনো মেমোরি থেকে বানাবে না; git/ফাইল/অডিও থেকে পুনরুদ্ধার করবে, না পেলে আবার generate করবে।

## M4. CSS selector-এ hex-escape টাইপো — rule মৃত [JWT/2026-10]
- **লক্ষণ:** সব card-এর ভেতরের লেখা কিনারা স্পর্শ করছিল; যতবারই padding/সেন্টারিং ঠিক করা হলো, কোনো পরিবর্তন এলো না (৩ সংস্করণ পর্যন্ত)।
- **কারণ:** rule লেখা হয়েছিল `.g\boxed{` — CSS-এ `\b` hex escape (U+000B), selector কখনো match করেনি; লেখা আসলে সম্পূর্ণ unstyled ছিল।
- **সমাধান:** selector `.gbox{` ঠিক + সব card block-layout + runtime self-heal JS।
- **নিয়ম:** যেকোনো CSS rule লেখার পর নিশ্চিত করবে selector টি class/element-এর সাথে byte-মিল; সব component-এর QA screenshot দেখবে (নিজের চোখে)।

## M12. ফাইল rename/replace করলে পুরো repo grep — পুরনো ref পিছিয়ে যায় [2026-10]
- **লক্ষণ:** videoDetails.txt → videoDetails.md করার পরও ৫টা জায়গায় পুরনো নামের reference থেকে গেছিল (README, skills 00/02/05/07, src/README)।

- **সমাধান:** চূড়ান্ত যাচাইয়ে grep-এ ধরা পড়ে সব ঠিক করা হলো।
